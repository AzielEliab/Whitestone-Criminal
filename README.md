## First screen

1. Install: `python3 -m pip install -e .`
2. Open the welcome: `whitestone-criminal`
3. Read it. That welcome is the only screen in this package.

`whitestone-criminal --help` lists the same commands. `whitestone-criminal --json` prints the same status for machines.

If the shell cannot find `whitestone-criminal`, run `python3 -m whitestone_criminal`. That prints the same welcome.
